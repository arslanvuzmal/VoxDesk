# VoxDesk Roadmap

This roadmap describes capability maturity, not promised dates. Checked items are present in the repository; activation and production verification remain separate states.

## Foundation

- [x] Canonical conversations, calls, CRM records, appointments, opportunities, tasks, follow-ups, and handoffs
- [x] Tenant-scoped authorization and server-owned tool execution
- [x] Telephony provider abstraction, Telnyx adapter, and deterministic simulation
- [x] Controlled outbound campaign policy, consent, suppression, window, and capacity controls
- [x] Supervised evaluation, candidate, canary, promotion, and rollback lifecycle

## Customer operations

- [ ] First-class support Case/Ticket domain
- [ ] Human queues, ownership, and collaborative internal notes
- [ ] SLA policies and breach operations
- [ ] Expanded Customer 360 timeline for cases and commitments

## Omnichannel

- [x] Web text and web voice architecture
- [x] Phone architecture with simulation mode
- [ ] Email adapter
- [ ] Contact-form ingestion adapter
- [ ] Messaging adapter architecture

## Quality and integrations

- [ ] Published QA scorecards and resolution-effectiveness reporting
- [ ] Customer feedback/CSAT workflow
- [ ] Verified external CRM, calendar, and helpdesk adapters as customer needs require

## Live telephony

- [ ] Customer Telnyx resources and SIP import
- [ ] Authorized inbound, outbound, concurrent, and transfer acceptance tests
- [ ] Production readiness evidence for the target customer environment
