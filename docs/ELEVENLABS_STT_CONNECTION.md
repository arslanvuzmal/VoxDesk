## ElevenLabs Voice Engine Pipeline

1. **Ephemeral STT Token Issuance**:
   - `/api/demo/stt-token` returns single-use ephemeral Scribe STT tokens for authorized sessions.
   - Client establishes Scribe Realtime STT connections while streaming mic audio.

2. **Honest Provider Labeling**:
   - Displays `ElevenLabs Scribe Realtime` when active.
   - Displays `Browser transcription fallback` when using Web Speech API.
   - Displays `Text input mode` when microphone access is denied.

3. **STT Lifecycle Disconnect (`POST /api/demo/stt-disconnect`)**:
   - Releases connection locks on mic stop, call end, page unload, or component unmount.

4. **TTS Voucher Security (`POST /api/demo/tts`)**:
   - Accepts single-use `responseId` vouchers generated by `/api/demo/respond`. Arbitrary text injection is rejected.
