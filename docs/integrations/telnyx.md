# Telnyx

Telnyx is the production PSTN/SIP and call-control boundary. VoxDesk verifies raw Telnyx events, resolves tenant routing from server-side records, persists idempotent provider events, and projects them asynchronously.

The public portfolio does not provision a Telnyx number or place calls. See [live activation](../guides/activate-live-telephony.md).
