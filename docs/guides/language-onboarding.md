# Language onboarding

Create a LanguageProfile for each business language. Keep it disabled until provider capability, business content, disclosures, tools, dates, numbers, and pronunciation are tested.

A verified profile requires provider testing, content review, tool tests, critical disclosure tests, date/time and number tests, pronunciation tests, and conversation evaluation. Important markets should receive native-speaker review.

Selection order is contact preference, assigned number language, explicit request, verified detection, business default, then human fallback. Never claim universal language support.
