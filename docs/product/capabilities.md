# Capabilities and Maturity

| State               | Meaning                                                        |
| ------------------- | -------------------------------------------------------------- |
| Implemented         | Repository code and tests support the capability.              |
| Configured          | Required settings are present; this is not a provider proof.   |
| Verified            | A safe, recorded test proved the target environment behavior.  |
| Simulated           | The public demo uses deterministic provider-normalized events. |
| Activation-required | Customer/provider resources are required before use.           |
| Planned             | Documented direction, not current product behavior.            |

Implemented foundations include canonical conversations, tenant-scoped CRM state, appointments, leads/opportunities, tasks, follow-ups, handoffs, campaign controls, Telnyx and ElevenLabs boundaries, simulation mode, and supervised improvement gates.

First-class support cases, queues, SLA management, email/form adapters, CSAT, and external helpdesk adapters are planned. They are not represented as active integrations or public-demo capabilities.
