# Support

Use GitHub issues for reproducible defects, documentation corrections, and scoped feature proposals. Use [private vulnerability reporting](SECURITY.md) for security concerns.

For deployment or client implementation work, provide the target commit SHA, environment, redacted health output, and whether the issue is in simulation or activated-provider mode. Never post credentials, full transcripts, or unmasked customer contact data.

VoxDesk's public deployment is a portfolio environment. Live PSTN, provider, and enterprise integration support requires customer-owned configuration and authorized testing.
